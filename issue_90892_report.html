Invoice – Bank icon is cropped

Issue URL: github.com/Expensify/App/issues/90892
GitHub Repo URL: github.com/Expensify/App
Environment: Reproducible in Production & Staging
Platform(s): Windows: Chrome
Version Number: v9.3.75-0

Action Performed

  1. Start with a workspace that has Invoice enabled and a receiver with a personal/business account added
  2. Send a USD invoice to the receiver
  3. As the receiver, open the invoice room
  4. Click the “Mark as paid” dropdown button on the invoice preview
  5. Select either “Pay as an individual” or “Pay as a business”

Expected Result

The bank icon is square and fully visible (bank name not cropped).

Actual Result

The bank icon is squeezed/distorted and the bank name is cropped.
